# History source assets

Only assets used by `p01-a01-history-origins` are included. Downloaded/captured
2026-11-06. Source pixels and wording are preserved; animated quotations are
separately typeset in the composition. No generative face or text enhancement.

- `apache-proposal.png`: native crop of the Apache Incubator Cassandra proposal,
  https://cwiki.apache.org/confluence/spaces/INCUBATOR2/pages/120720730/Cassandra .
  The page's 2019 update metadata is not the development date. The relevant
  Background sentence explicitly says June 2007.
- `facebook-title.png`, `facebook-excerpt.png`: native crops of Avinash Lakshman's
  August 25, 2008 article, https://engineering.fb.com/2008/08/25/core-infra/cassandra-a-structured-storage-system-on-a-p2p-network/ .
  Header and opening paragraph are joined as an editorial excerpt; the
  intervening illustration is omitted. Preserve the source spelling `Hackthons`.
- `dynamo-page.png`: first page of the original Dynamo paper,
  https://cdn.amazon.science/ac/1d/eb50c4064c538c8ac440ce6a1d91/dynamo-amazons-highly-available-key-value-store.pdf .
  Converted directly from the PDF at 1600 px page height. Full author list is
  retained. This is Dynamo (2007), not the later DynamoDB product.
- `avinash-lakshman.jpg`: 650×433, photo credit S.L. (Serge Leblal),
  Le Monde Informatique, June 25, 2015:
  https://www.lemondeinformatique.fr/actualites/lire-silicon-valley-2015-stockage-distribue-et-virtualise-chez-hedvig-61568.html .
- `prashant-malik.jpeg`: 542×566, official Tykhe team portrait,
  https://www.tykhe.ventures/team/ ; original image:
  https://www.tykhe.ventures/wp-content/uploads/2025/04/images-4.jpeg .
  Photograph date unknown; it is not presented as a 2007 photograph.
- `inbox-2008.png`: 643×242, Justin Smith, Inside Facebook, June 19, 2008.
  https://web.archive.org/web/20080829234751/http://www.insidefacebook.com/2008/06/19/facebook-launches-inbox-search-screenshot/ .
  Original image recovered from:
  https://web.archive.org/web/20080829234751id_/http://www.insidefacebook.com/wp-content/uploads/2008/06/facebookinbox.png .
  The original search query is `stanford`. Russian messages in the following
  demonstration are fictional examples, not translations of these messages.
