# Reference animations

Восемь канонических визуальных референсов: пять 2D и три 3D. Каталоги — стабильные точки входа, а общие примитивы исходных исследований сохранены в `shared/`.

Референсы нужны для сравнения новых работ с утверждённым визуальным языком. Продуктовые компоненты следует брать из `packages/`, а не копировать отсюда.
