# Animations for YouTube

Набор кодовых 2D- и 3D-анимаций для YouTube-канала о computer science.

> Проект находится в стадии подготовки. Позже здесь появятся описание пайплайна,
> превью композиций и правила экспорта.

## Стек

- Remotion
- React + TypeScript
- Three.js / React Three Fiber

## Запуск

```bash
cd cs-dataflow-motion
pnpm install
pnpm studio
```
