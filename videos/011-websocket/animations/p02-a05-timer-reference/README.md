# Таблица таймеров и чек-лист

В Studio открыть `Video-011-websocket-p02-a05-timer-reference`. Композиция занимает 08:16,060–08:39,000 по монтажу. Первая реплика начинается в 08:08,060 исходного WAV, реплика о чек-листе — в 08:19,440. Для восстановления звука Studio выполните из корня проекта

```sh
ffmpeg -ss 488.06 -i ~/Movies/CapCut/websocket_audio.WAV -t 22.94 -ac 1 -ar 48000 -c:a aac -b:a 96k apps/remotion/public/generated/011-websocket/timer-reference.m4a
```

Содержимое обоих экранов взято из `~/Downloads/WebSocket_в_проде_все_материалы.md`. В `timers.ts` сохранён порядок строк. На первом экране — тема 2, §5 «Таблица таймеров на ноябрь 2026 года», три колонки. На втором — тема 2, §10 «Найти звено по числу секунд». В теме 8 специально оговорено, что предполагаемые 100 секунд у Cloudflare нельзя показывать как факт. В чек-лист эта строка не вошла.
