## Вертикальная серия в Remotion

Открой `V-010-binance → Shorts` или `V-010-binance → TikTok`. Нумерация тем одинакова
в обеих папках. Монтаж, субтитры и рисунок каждой темы находятся в
`broker-shorts/p01-aNN-…`; TikTok использует тот же материал со своей компоновкой
и концовкой. `shared/vertical` содержит общую рамку, рисунки и концовки серии.
Правила для новых тем записаны в [AGENTS.md](AGENTS.md).

Для восстановления локальной вебки и голоса используй исходные записи и монтажные
отрезки из `cuts.json`. Например, из корня репозитория:

```sh
python3 videos/010-binance/shared/vertical/prepare_presenter.py \
  videos/010-binance/broker-shorts/p01-a02-cancel-race \
  '/Users/mdpopov/Desktop/binance/2026-11-16 14-48-11.mp4' \
  '/Users/mdpopov/Movies/CapCut/binance_audio.WAV'
```

У двух платформ общий источник для предпросмотра в `public/generated/010-binance`.
