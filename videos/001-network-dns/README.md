# Network DNS

Первое production-видео канала. Формат: 2560×1440, 30 fps.

| Раздел | Якорь | Композиция |
| --- | ---: | --- |
| Что такое DNS и зачем он нужен | `00:55.040` | `Video-001-network-dns-p01-a00-chapter-divider` |
| Детальный разбор: как DNS работает | `03:56.760` | `Video-001-network-dns-p02-a00-chapter-divider` |
| Безопасность, приватность и мифы | `12:57.060` | `Video-001-network-dns-p03-a00-chapter-divider` |
| Заключение | `18:49.420` | `Video-001-network-dns-p04-a00-chapter-divider` |

Все разделители длятся четыре секунды и используют локальный
`shared/DnsChapterDivider.tsx`. Точный монтаж задают `anchors.json` и
`timeline.json`; полный транскрипт хранится в `transcript.json`.

## Интро-вставки

| Вставка | Якорь | Длительность |
| --- | ---: | ---: |
| «В этом видео» | `00:11.140` | `23.360 сек` |
| Подписка на канал | `00:51.720` | `3.000 сек` |

`p00-a01-episode-agenda` синхронизирован с четырьмя тезисами вступления и оставляет
правую часть кадра свободной для ведущего. `p00-a02-subscribe-callout` использует
глобальный `Standard-Subscribe`, фиксируя только текст и положение для выпуска.

## Нумерация

Композиции имеют идентификатор `pNN-aNN-slug` и сгруппированы в Studio по части.
`p00` содержит общие вставки выпуска; `a00` зарезервирован для разделителя части.
