# Локальная библиотека выпуска

Размещайте здесь компоненты, используемые несколькими анимациями этого выпуска. Компоненты одной сцены оставляйте в её каталоге внутри `animations/`.

`theme.ts` задаёт локальную тёмную палитру и размеры области графики. `HashingStage.tsx` создаёт SVG-холст 2560×1440 и подложку с прозрачным краем через общий `FeatheredBackground`. Подложка затухает отдельно от текста и схемы. Для проверки композиции доступны светлый и тёмный фон; в монтажной версии используется прозрачный.
