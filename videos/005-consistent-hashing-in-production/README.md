# Кольцо под нагрузкой: consistent hashing на проде

Формат: **2560×1440, 30 fps**. Первая сцена — `p00-a01-production-experiment`: один экземпляр сервиса превращается в кластер, затем под нагрузкой добавляется новая нода и отключается одна из прежних.

`transcript.json` и `anchors.json` относятся к начальному аудиофрагменту длительностью **339429 мс**. Это не длительность полного видео. Сцена размещена на **00:32.520–01:00.000**, начиная со слов про статьи с Википедии. Аудио подключено через локальный ingest.

## Запуск и проверка

Из корня репозитория:

```bash
task studio
task video:validate VIDEO=005-consistent-hashing-in-production
task check
```

В Studio откройте `Video-005-consistent-hashing-in-production-p00-a01-production-experiment`. У отдельной композиции звук включён по умолчанию; `withAudio: false` отключает его. `previewBackground` принимает `transparent`, `light` или `dark`. Для монтажа нужен `transparent`; остальные варианты предназначены для проверки края и читаемости.

В общей композиции выпуска звук подключается один раз, а сцена получает `withAudio: false` из `timeline.json`. Схема увеличена в 1,4 раза и занимает область до x=1308. Фон сплошной до x=1380 и полностью исчезает к x=1740, оставляя место для ведущего справа.

## Добавление материалов

Используйте `task animation:new` с параметрами `VIDEO`, `PART`, `ORDER`, `ANIMATION`, `TITLE`. После создания сцены задайте якорь в `anchors.json` и размещение в `timeline.json`.

Для подключения аудио используйте `task video:ingest` с параметрами `VIDEO`, `AUDIO`, `TRANSCRIPT`. После замены или перемонтажа аудио повторно проверьте длительность и речевые якоря. Время хранится в миллисекундах от начала соответствующего исходного файла.

В каталоге анимации `state.ts` содержит время и геометрию, `ExperimentDiagram.tsx` — схему и движение запросов, `ExperimentCopy.tsx` — подписи, `Composition.tsx` — синхронизацию со звуком и появление/исчезновение сцены. Локальные цвета и ширины находятся в `shared/theme.ts`. При изменении распределения записей проверяйте переход целиком: строки сначала сужаются, затем расходятся по горизонтали и только после этого занимают свои ряды в нодах.
