## Изменение реализации

- `shared/chapters.ts` — номера и смысловые переносы названий.
- `shared/GeometryChapterDivider.tsx` — общая постановка выбранного варианта.
- `shared/ChapterStage.tsx` — сцена, локальный шрифт и тема.
- `shared/chapter-motion.ts` — профили и фазы движения в миллисекундах.
- `animations/*/Composition.tsx` — отдельные точки входа глав.

Props: `themeId` задаёт оформление; `motionProfile` — скорость входа.
Стандарт: `graphite` / `calm`. Профиль не меняет момент выхода.
Manrope с кириллицей загружается локально из public/assets под OFL.

Пользователь разрешил экспорт четырёх отдельных MOV. Полноэкранный непрозрачный
мастер: QuickTime ProRes 422 HQ, yuv422p10le, QHD, 30 fps, 135 кадров, без аудио.
Другие рендеры запускать только по отдельному запросу. Проверять в Studio
кадры 0, 6, 15, 24, 36, 45, 60, 90, 112, 120, 130, 134 и воспроизведение.
Проверять длины строк, маску, безопасные поля, читаемое удержание и полный выход.
Экспорт разрешён только после отдельного запроса пользователя.
