# TikTok: Cassandra и ScyllaDB

В Studio папка `TikTok` содержит общую пятисекундную концовку
`Video-009-cassandra-scylladb-p00-a02-tiktok-end-card`.
Название директории `tictok` задано пользователем.

Концовка сохраняет обложку, добавляет название выпуска и канал
[YouTube @ma_popov](https://www.youtube.com/@ma_popov). Стрелки нет:
TikTok не показывает ссылку на связанный YouTube-выпуск под видео.
Композиция статична все пять секунд, чтобы текст можно было спокойно прочитать.

Под названием выпуска размещён реальный скрин шапки канала: аватарка,
название, handle и кнопка «Подписаться». Источник —
https://www.youtube.com/@ma_popov, захвачен 11.11.2026 без входа в аккаунт.
Файл `public/assets/009-cassandra-scylladb/tictok/youtube-channel.jpg` —
необходимый материал композиции; счётчики на нём относятся к дате снимка.

## Запас под интерфейс TikTok

`layout.json` задаёт поля в координатах 1080×1920. Основная сцена целиком
масштабируется до 75% и располагается в x=36, y=210: нижний край y=1650,
правый x=846. Ничего не обрезается, пропорции камеры и схем сохраняются.
Концовка имеет собственную крупную типографику внутри x=36–900, y=210–1650.
Для 1440×2560 координаты пересчитываются пропорционально.

Это запас по пользовательскому превью TikTok от 11.11.2026, а не универсальная
гарантия для всех телефонов и раскрытых описаний. Проверять начало, смены сцен
и концовку с верхней навигацией, правыми кнопками и подписью ленты.
[TikTok о зависимости safe zone от интерфейса и длины подписи](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads).

`shorts.json` перечисляет 25 утверждённых экспортов. Скрипт заменяет последние
150 кадров, сохраняет исходное разрешение и количество кадров, копирует AAC
без перекодирования, проверяет хеш аудио и полностью декодирует результат.
Основная видеодорожка перекодируется H.264 CRF 16. Цвет явно нормализуется
в BT.709 до склейки; для старых MP4 без метаданных используется интерпретация
BT.601, принятая FFmpeg по умолчанию. Исходники не изменяются.
Обложки копируются; подписи получают название полного выпуска и ник канала.

Запуск из корня проекта (рендеры только по запросу пользователя):

```sh
task generate
pnpm --filter @channel/remotion exec remotion still src/index.tsx Video-009-cassandra-scylladb-p00-a02-tiktok-end-card /tmp/tiktok-end-card.png --frame=0
python3 videos/009-cassandra-scylladb/tictok/package.py \
  --scylla-source "$HOME/.Trash/cassandra-scylladb-shorts-20261110-152626/upload/scylla-shorts" \
  --card /tmp/tiktok-end-card.png \
  --output '/Users/mdpopov/Documents/ChatGPT/New project/outputs/tictok'
```

Указать `--trash`, если исходные MP4 восстановлены в другую папку с той же
структурой. Для обновления существующих MP4 добавить `--replace`: новый файл
заменяет прежний только после проверки звука, кадров и полного декодирования.
После визуальной проверки удалить временный
PNG и файлы QA. Итоговые комплекты находятся вне Git, в `outputs/tictok`,
по сериям `architecture`, `history`, `scylla`.
