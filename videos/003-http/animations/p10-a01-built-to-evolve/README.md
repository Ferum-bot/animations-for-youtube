# Создан, чтобы развиваться

Спокойная итоговая вставка слева поверх ведущего. Две читаемые фазы: расширяемое
ядро HTTP и общий протокол приложений. Три расширения появляются под слова автора,
затем уступают место браузеру, приложению и сервису. Один запрос и один ответ
между браузером и сервисом завершают схему; приложение не изображается прокси.

Studio: `http://localhost:9000/Video-003-http-p10-a01-built-to-evolve`.
Папка `P-11-Chto-vazhno-zapomnit`. 2560×1440, 30 fps, 717 кадров / 23,9 секунды.
По умолчанию в редакторе включены исходный голос и предоставленное фото ведущего.
Общий timeline использует прозрачный фон и не дублирует звук.

## Устройство

`timing.ts` хранит привязки к якорям, `Diagram.tsx` — локальную графику,
`Composition.tsx` — сборку. Переиспользованы `NarratedHttpScene`, `HttpStage`,
`TimedCopy`, временные функции и палитра выпуска. Фон плавно уходит в прозрачность
к x=1740. Только frame-driven SVG/React; постоянных циклов и случайности нет.

Для приёмки: `out/qa/http/finale/` — начало, появление каждого расширения,
обе стадии смены состояния, обмен, удержание, выход, светлый/тёмный фон.
MOV экспортировать отдельным запросом через `task render:capcut`.
