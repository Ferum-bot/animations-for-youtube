## Синхронизация

Источник — `transcripts/http-2026-09-13/blocks/block-06.json` (локальный Whisper), нормализованный `transcript.json` и существующие уточнения Referer. База исходного WAV: 633206 мс, фраза «Заголовки — это, по сути, параметры вызова». Голосовые якоря `p05-*` находятся в `anchors.json`; локальные времена вычисляет `shared/headers/timing.ts`. Последняя фраза заканчивается на 768566 мс. Галлюцинация распознавания «Продолжение следует» после неё не включена.

Общий просмотр играет одну непрерывную дорожку. Границы последовательностей округляются по абсолютным положениям относительно начала части, чтобы независимое округление длительностей не создавало зазор или наложение в один кадр. Фото ведущего — только подложка для проверки композиции. В production timeline входят четыре прозрачные анимации без аудио, preview в timeline не входит. Таймкоды CapCut потребуют фактического начала этой фразы после уже смонтированного разделителя.

## Визуальное устройство

Сохранены синий фон, мятный акцент, крупные заголовки и прозрачность справа. Контент внутри x=136…1256. Подложка использует существующую проверенную маску, полностью прозрачную при x≥1740.

В Host и Upgrade применяется 2.5D: согласованные грани SVG с параллельной проекцией. Сервер раскрывается в три сайта, селектор останавливается на Host. В Upgrade поворот механизма сопровождается раскрытием двух направлений обмена, движение пакетов проходит за корпусом и не перекрывает обозначения. Это управляемая геометрия, не WebGL. Состояния вычисляются из кадра; случайности, непрерывной камеры, размытия, частиц и фильтров нет.

В коротком эпизоде cookies два последовательных направления; в остальных сценах — вход, смысловой акцент и удержание. Подмена Referer/User-Agent очищает только слот значения. Тёплый цвет отмечает изменяемые сведения клиента.

## Техническая точность

- Accept задаёт предпочтения, фактическое представление выбирает сервер. Примеры заголовков — фрагменты, не полные сообщения.
- User-Agent сообщает программу и версию, не удостоверяет личность.
- Ответ Set-Cookie сохраняет значение; Cookie возвращает его в последующем запросе соответствующего сайта.
- Кэш иллюстрирует свежесть, условный GET с If-None-Match и 304. Шкала времени условная. Не показаны неподтверждённые проценты использования кэширования.
- Обязательность Host ограничена HTTP/1.1; IP общий для нескольких сайтов.
- Referer — закреплённое имя с исторической опечаткой. Значение — URI источника, поле может отсутствовать. Неуверенный фрагмент Whisper про «несуществующий IP/API» не превращён в техническое утверждение.
- Подмена Referer/User-Agent не изменяет IP соединения, не подтверждает страну или пользователя. CDN может проверять запросы, но само наличие посредника не делает произвольные поля доверенными.
- Upgrade показан для HTTP/1.1 после успешного рукопожатия с 101. Это продолжение соединения другим протоколом, не редирект. На экране только ключевые фрагменты рукопожатия; полная процедура WebSocket здесь не разбирается.

Основания: [HTTP semantics](https://www.rfc-editor.org/rfc/rfc9110.html), [Host](https://www.rfc-editor.org/rfc/rfc9112.html#section-3.2), [cookies](https://www.rfc-editor.org/rfc/rfc6265.html#section-3.1), [WebSocket opening handshake](https://www.rfc-editor.org/rfc/rfc6455.html#section-1.3).

## Архитектура и проверка

Код эпизодов остаётся в соответствующих папках анимаций. Общие строки заголовков, подписи, проекционная пластина и рисуемые маршруты находятся в `shared/headers/Elements.tsx`; время отдельно в `shared/headers/timing.ts`. Переиспользуются HttpStage, NarratedHttpScene, HttpDiagram и существующая тема. При проходе по дублированию одинаковые интервалы появления/перелёта вынесены из status/timing в общий shared/timing; прежний импорт совместим через re-export. Межвидео-пакеты не расширялись.

QA-кадры и план: `out/qa/http/headers/`. Проверяются пустой кадр, вход, первое читаемое состояние, все смысловые переходы, удержание и выход, светлая/тёмная подложки, область ведущего, повторяемость кадров. После проверки в редакторе пользователь одобрил экспорт всех четырёх MOV; сведения ниже.

Результат QA: проверены 91 ключевой кадр на подложке ведущего и 48 кадров на прозрачной, светлой и тёмной подложках. Повторный рендер четырёх контрольных кадров совпал побайтово. Последние кадры пустые, альфа справа от x=1740 равна нулю. `task check` проходит; единственное прежнее предупреждение — отсутствующее локальное аудио видео 001-network-dns. Редактор на порту 9000 отвечает HTTP 200.
