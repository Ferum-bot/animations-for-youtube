подсветка JetBrains, плавный вход 900 мс и выход 1100 мс через общий CodeBoard.

финальное удержание и выход. Проверены светлая/тёмная подложки, safe area,
стрелки, подписи, кириллица, отсутствие пересечений и обрезания.
