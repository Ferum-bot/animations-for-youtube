# Атомарная резервация PostgreSQL

Предварительная полноэкранная сцена к речи 10:08.220–12:29.300.

## Визуальное решение

Весь SQL виден с первого читаемого кадра, без набора по буквам и прокрутки.
Код: 36 px, межстрочный шаг 51 px; пояснение справа: заголовок 45 px, текст 29 px.
Тёмная подложка занимает весь экран и имеет непрозрачность 94%.
Текст остаётся непрозрачным. Акценты голубые, подписи розовые, строки зелёные.
Вход 10 кадров, выход 12 кадров; смена подсветки 280 мс.

`backgroundOpacity` управляет непрозрачностью подложки (0…1).
`previewBackground`: `transparent`, `light`, `dark` — фон для предпросмотра.
`withAudio: true` включает соответствующий отрезок оригинального голоса в Studio.
`themeId` — токены визуальной темы, по умолчанию graphite.

## Ответственности

- `Composition.tsx`: сцена, подложка, аудио и общий вход/выход.
- `sql.ts`: SQL пользователя с нормализованным Markdown/HTML-экранированием и локальный lexer.
- `cues.ts`: выбранные строки и короткие пояснения, время из anchors.json.
- `SqlListing.tsx`: синтаксис, номера строк и плавная подсветка.
- `Explanation.tsx`: подписи к текущему фрагменту.

SQL не менялся семантически. Нет отдельного SELECT перед UPDATE; резерв создаётся
из строк RETURNING CTE. Подсветка объясняет код, а не изображает реальное выполнение транзакции.

## Проверка

`task check` проходит. Предупреждения относятся только к отсутствующему аудио трёх старых видео.
Проверены 24 ключевых PNG: пустой кадр, вход, все 18 пояснений, переход, финальное удержание, выход.
Проверены композиции поверх светлого и тёмного фона; поля, длинная строка INSERT,
русские подписи, синтаксис и границы подсветки помещаются в кадр.
На первом и последнем кадре alpha=0; на подложке удержания alpha=240/255.
Кадры и листы проверки: `out/qa/ozon-reservation/`, основной пример — `preview.png`.
Это проверка исходной композиции; MOV/CapCut-мастер ещё не экспортировался.

После обзора packages и локальных библиотек старых эпизодов SQL-компоненты оставлены
локально: существующий HttpCode обслуживает другой формат и не поддерживает эти акценты.
Используются общие fadeEnvelope, smoothProgress, msToFrames и theme-токены.
Состояние вычисляется только из кадра и props, без таймеров, случайности и эффектов.
