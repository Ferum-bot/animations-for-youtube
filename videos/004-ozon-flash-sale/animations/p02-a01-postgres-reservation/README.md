# Атомарная резервация PostgreSQL

Предварительная полноэкранная сцена к речи 10:08.220–12:29.300.

## Визуальное решение

Весь SQL виден с первого читаемого кадра, без набора по буквам и прокрутки.
Код: 36 px, межстрочный шаг 51 px; пояснение справа: заголовок 43 px, текст 29 px.
Светлая доска Freeform с редкой точечной сеткой занимает весь экран и имеет непрозрачность 100%.
Текст остаётся непрозрачным. Синтаксис по референсам JetBrains: оранжевые ключевые слова, фиолетовые поля,
зелёные строки, бирюзовые числа, синие функции, золотистые параметры и оливковый CTE.
Имена таблиц и пунктуация остаются графитовыми; функции и параметры выделены курсивом.
Оттенки адаптированы для контраста на светлой доске.
Активные строки выделены охристым маркером, темы пояснений — тонкой лиловой обводкой.
Референсы: IMG_0080.PNG и IMG_0081.PNG из Downloads.
Плавное появление всей сцены: 900 мс (27 кадров); исчезновение: 1100 мс (33 кадра).
Кривая cubic ease-in-out, с нулевой альфой на первом и последнем кадре.
Смена подсветки 280 мс.

`backgroundOpacity` управляет непрозрачностью подложки (0…1).
`previewBackground`: `transparent`, `light`, `dark` — фон для предпросмотра.
`withAudio: true` включает соответствующий отрезок оригинального голоса в Studio.
`themeId` — токены визуальной темы, по умолчанию paper.

## Ответственности

- `Composition.tsx`: сцена, подложка, аудио и общий вход/выход.
- `sql.ts`: SQL пользователя с нормализованным Markdown/HTML-экранированием и локальный lexer.
- `cues.ts`: выбранные строки и короткие пояснения, время из anchors.json.
- `SqlListing.tsx`: синтаксис, номера строк и плавная подсветка.
- `Explanation.tsx`: подписи к текущему фрагменту.

SQL не менялся семантически. Нет отдельного SELECT перед UPDATE; резерв создаётся
из строк RETURNING CTE. Подсветка объясняет код, а не изображает реальное выполнение транзакции.
