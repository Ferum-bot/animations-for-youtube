# Резервация Redis + Lua

Сцена: `Video-004-ozon-flash-sale-p03-a01-redis-lua-reservation`.
Интервал исходного ozon_sd.WAV: **21:22.920–22:53.480** (90560 мс).
Производство: 2560×1440, 30 fps. Вход 900 мс, выход 1100 мс, cubic ease-in-out.
Подложка полностью непрозрачная между переходами, светлая точечная доска.

## Содержание

Lua пользователя сохранён семантически. Длинный комментарий с входными данными
разнесён на четыре строки; однострочные if разнесены на блоки для читаемости.
Подсветка JetBrains: ключевые слова оранжевые, функции синие, строки зелёные,
числа бирюзовые, KEYS/ARGV золотистые, локальная переменная фиолетовая.

16 пояснений по anchors.json: обзор, входные ключи, stock, holders, user_id, TTL,
проверка повтора, return -1, GET, проверка остатка, DECR, SADD, return 1,
атомарность, один round trip.

ARGV[2] объявлен в комментарии, но не читается скриптом. В момент упоминания TTL
подпись прямо отмечает, что срок брони этот фрагмент не устанавливает.
Скрипт не дополнен EXPIRE и не изменён ради согласования с речью.
Вместо неточного «кто купил» из распознавания используется «держатели брони».

## Архитектура и просмотр

- `lua.ts`: исходный фрагмент и локальный lexer.
- `cues.ts`: диапазоны строк и пояснения; время из абсолютных speech anchors.
- `Composition.tsx`: связывает данные сцены с общими компонентами.
- `../../shared/code/`: CodeBoard, CodeListing, CodeExplanation и типы.
