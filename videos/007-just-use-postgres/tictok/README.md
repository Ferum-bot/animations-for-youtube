# TikTok — Just Use Postgres

These are complete compositions, not post-export resizes of the Shorts files.
They share the episode's vertical body, audio and safe layout with `../intro-shorts`
and select the YouTube-channel outlet through `platform: "tiktok"`.

Source code, rendering commands and extension rules: `../intro-shorts/README.md`.
Ready-to-upload exports belong in the episode's ignored `output/tictok/` folder.
Do not add a YouTube related-video arrow or a promise of a clickable description
link to this platform's outlet. Show the actual episode thumbnail and channel.
