# Just Use Postgres episode rules

All subsequent code snippets, raw source listings, commands, and configuration
examples in this episode use `shared/CodeSnippet.tsx`: a clearly separated dark
rectangular surface, a thin visible border, consistent internal padding, and a
small language/type or filename label in the upper-right corner (SQL, JSON,
BASH, a source filename, etc.). Do not place multi-line code directly on the
scene background. Explanatory prose and query results stay outside the code
surface. Preserve readability and check the added block dimensions during
full-screen-to-left-panel transitions.

This episode-wide convention was explicitly requested by the user on
2026-10-18. It applies to future animations; do not retroactively change
previously approved/exported animations without a request.

Use the supplied episode materials as the source of technical examples. Keep
necessary context visible: introduce tables and field meanings before queries,
show complete relevant SQL definitions rather than unexplained fragments, and
connect source data to the displayed result. Simplification must not remove
information needed to understand the example. Align examples to the recorded
narration, and flag material disagreements instead of silently inventing data.
