# Working principles

## Git

Никогда не создавать commit и не выполнять push без прямой просьбы пользователя.

## Код

- SOLID, DRY и KISS обязательны.
- Код декомпозирован по ответственности, читается без расшифровки и не скрывает поведение за магией.
- Используется строгий современный TypeScript: точные типы, narrowing, discriminated unions, `satisfies`, readonly-данные и исчерпывающие проверки.
- После каждой новой анимации проводится рефакторинг не только изменений, но и всей кодовой базы: поиск дублирования, выделение локальных компонентов и перенос устойчивых контрактов в `packages/`.
- Имена анимаций следуют схеме `pNN-aNN-slug`. Номер части и порядок обязательны и совпадают в папке, manifest, timeline и Remotion composition ID.

## Приёмка анимации

- Проверяются вход, читаемое состояние, каждый смысловой переход, кульминация, финальный hold и выход.
- Не допускаются clipping, наложения, случайные артефакты, пересечения линий, выезд за safe area и нечитаемая типографика.
- Для прозрачной графики проверяется светлый и тёмный фон.
- Для CapCut macOS использовать `task render:capcut VIDEO=... ANIMATION=...`: RGB согласуется с альфой до кодирования ProRes. Полный FFmpeg с фильтром `premultiply` должен быть доступен в PATH; сборка FFmpeg внутри Remotion не содержит этого фильтра. Проверять готовый MOV через `task qa:capcut-alpha INPUT=...` и край градиента в масштабе 100% в самом CapCut. Один лишь формат `yuva444p` и предпросмотр PNG не защищают от цветных полос при почти нулевой альфе.
- Production-формат: `2560x1440`, `30fps`.
- Полное видео самостоятельно не собирается. Для приёмки используются ключевые still-кадры; clip или overlay рендерится только по прямой просьбе.

Полный технический и визуальный контракт находится в [`AGENTS.md`](AGENTS.md).
