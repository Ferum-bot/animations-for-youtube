# Часы ожидания

Одна стрелка показывает течение времени, пока ведущий пишет код или ждёт
результат. Это условный символ, без отсчёта реальных секунд и процентов.
Циферблат и 12 делений неподвижны. Звука нет.

## Композиции в Remotion Studio

В папке `Standard`:

| Композиция | Тема | Поведение |
| --- | --- | --- |
| `Standard-Waiting-Clock-Light` | Светлый циферблат, тёмные деления | 10 секунд, вход и выход |
| `Standard-Waiting-Clock-Dark` | Тёмный циферблат, светлые деления | 10 секунд, вход и выход |
| `Standard-Waiting-Clock-Light-Loop` | Светлая | Бесшовный цикл 3 секунды |
| `Standard-Waiting-Clock-Dark-Loop` | Тёмная | Бесшовный цикл 3 секунды |

Все композиции — `2560×1440`, `30 fps`. Фон прозрачный, сам циферблат
непрозрачный. Тонкий кант противоположного цвета отделяет внешний обод
от пёстрого видео. Цвета берутся из семантических токенов канала.

## Настройки

- `themeId`: `paper` или `graphite`; также поддерживается общая тема `signal`.
- `sizePx`: диаметр на QHD-холсте, по умолчанию `192`; диапазон `96–320`.
- `placement`: `bottom-left` (по умолчанию) или `top-left`.
  Отступ от краёв — `100 px`, движение при входе/выходе направлено внутрь кадра.
- `motionProfile`: `calm` (оборот за `3000 ms`), `technical` (`2400 ms`),
  `energetic` (`1500 ms`). Скорость не зависит от темы или длительности вставки.
- `playback`: `{mode: 'overlay', durationMs: 10000}` для вставки с входом/выходом
  либо `{mode: 'loop'}` для ровно одного полного оборота без затухания.
  Минимальная длительность отдельной overlay-композиции — `1000 ms`.

В профиле `calm` появление занимает 9 кадров, уход — 12. Стрелка вращается
равномерно по часовой стрелке и не тормозит на границе цикла. Нулевой и
последний кадры overlay полностью прозрачны. У loop все кадры видимы:
при повторении нет паузы или повторного кадра на стыке.

`calculateMetadata` обновляет длительность зарегистрированной композиции по
`playback` и `motionProfile`. Для изменения длительности в Studio меняйте
`playback.durationMs` в props.

## Использование внутри видео

```tsx
import {Sequence} from 'remotion';
import {msToFrames} from '@channel/motion-core';
import {WaitingClock, waitingClockDefaultProps} from '@channel/standard-animations';

const durationMs = 12000;

<Sequence from={startFrame} durationInFrames={msToFrames(durationMs, fps)}>
  <WaitingClock
    {...waitingClockDefaultProps}
    themeId="graphite"
    playback={{mode: 'overlay', durationMs}}
  />
</Sequence>;
```

Внутри `<Sequence>` вход и выход привязаны к локальному кадру и фактической
длительности Sequence. Задавайте ей ту же длительность, что и `durationMs`.
Режим `loop` можно помещать в Sequence любой длины — вращение продолжится
без затуханий. Компонент не читает часы, окружение или случайные значения.

Для монтажа одной вставкой используйте overlay нужной длины. Для повторения
используйте loop; склейка overlay-вариантов создаст промежуточные затухания.
MOV для CapCut экспортируется только по отдельному запросу через утверждённый
в проекте pipeline ProRes 4444 с premultiplied alpha и проверкой готового файла.
