# Motion v2 — текущая библиотека канала

Новые анимации используют `@channel/motion-v2`. Пользователь утвердил этот
подход на истории Cassandra и 07.11.2026 поручил сделать его общим стандартом.
Это рабочие компоненты утверждённых сцен, а не новая стилистическая концепция.

Обязательные правила: [гайд анимаций](../../docs/style/ANIMATION_GUIDE.md) и
[простые объяснения с референсами](../../docs/style/PLAIN_EXPLANATION.md).
Common Craft, Maggie Appleton и Julia Evans задают простоту предметов и примеров;
Nicky Case / Red Blob Games — причинность. Геометрическая заставка сохраняет
выбранное направление MKBHD / Posy / Ben Marriott. Не смешивать все приёмы в кадре.

## Контракт

- QHD 2560×1440, 30 fps, нативные SVG-координаты. Graphite / cream / cobalt и
  локальный Manrope с кириллицей. Шрифт и OFL находятся в `public/assets/channel-v2/fonts/`.
- Одна задача кадра, конкретные предметы, минимум подписей, короткое действие и
  читаемый hold. Без постоянного движения, шума, частиц, HUD и универсальных карточек.
- Слева: x=100, панель не шире 1080; справа оставить ведущего. Полноэкранные
  сайты — от края до края, без рамки. Реальная страница → скролл к точному месту →
  выделение целых слов → увеличенная цитата, набранная текстом.
- Все движения вычисляются из миллисекунд. Время из кадра получать на границе
  композиции; данные, текст, источники и синхронизацию с голосом хранить в выпуске.
- Публичные props сериализуемые; `children` — обычный внутренний React composition.
  Библиотека не импортирует выпуски и не содержит конкретных цитат или таймингов речи.
- Новое поведение сначала реализовать локально. После пользовательского принятия
  выделять устойчивый контракт в v2, удалять дублирование, проверять старых потребителей.
  Не создавать каталоги декоративных демо и не переносить сюжет целиком в библиотеку.

## API

| Экспорт | Назначение |
| --- | --- |
| `SceneStage`, `useSceneTime` | QHD SVG, шрифт, семантические цвета; явная прозрачность и opacity, без автоматического fade |
| `arrive`, `presence`, `progress`, `easing`, `mix` | Ограниченные жесты, переходы и hold в миллисекундах |
| `MessageIcon`, `Magnifier`, `Pocket`, `Slip`, `Sheet` | Фиксированные авторские контуры; пузырь сообщения принимает собственный текст |
| `SourceImage` | Реальное изображение в SVG; Remotion ожидает декодирование |
| `SourcePage` | Полноэкранная страница, скролл, исходные прямоугольники выделения, blur; цитата остаётся отдельным чётким текстом |
| `PresenterPreview`, `PreviewProps` | Одна фотография и короткий аудиофрагмент по явным путям; default — прозрачность и тишина |
| `GeometryChapterDivider`, `ChapterTitle` | Утверждённая анимация трёх плоскостей; номер, две строки и размеры шрифта передаёт выпуск |
| `v2Theme`, `getV2Theme`, `productionCanvas`, `presenterSafeLayout` | Тема, шрифт и ограничения компоновки |

```tsx
import {SceneStage, MessageIcon, arrive, useSceneTime} from '@channel/motion-v2';

export const Composition = () => {
  const {timeMs} = useSceneTime();
  return <SceneStage label="Сообщение сохранено">
    <g opacity={arrive(timeMs, 0, 300)}>
      <MessageIcon x={160} y={420} scale={2} />
    </g>
  </SceneStage>;
};
```

`SourcePage` принимает координаты из оригинального снимка (`sourceWidth`,
`sourceHeight`, `scrollY`, `highlights`). `selection` и `blur` вычисляет сцена.
Смысловые тайминги не прятать в компонент. Для PDF с отдельной колонкой или
раскрывающейся левой панели использовать `SourceImage` и локальную маску.

Для заставки передать `chapter={{number: '01', lines: ['Название', 'части'],
fontSizes: [176, 220]}}`; длительность в metadata — 4500 ms. Проверить все
конкретные названия: размеры шрифта не гарантируют, что произвольная строка войдёт.

## Работа и совместимость

`task animation:new` создаёт v2-сцену и `designSystem: "v2"` в `animation.json`.
`task check` проверяет типы, manifest, таймлайн, запрет legacy-импортов и тесты
генераторов. Старые композиции перечислены в `config/design-system-policy.json`
как `deprecated-for-new-work`: их можно поддерживать и воспроизводить, но нельзя
брать за основу новой сцены. Не пополнять этот список ради обхода проверки.

`@channel/design-system`, `@channel/standard-animations`, старые episode-local
визуальные наборы и восемь frozen examples deprecated для нового дизайна.
Их композиции и ID сохранены; Studio помечает их папки `Deprecated-*`.
`@channel/theme`, `@channel/motion-core`, `@channel/audio-sync` и экспортный
pipeline — действующая инфраструктура, не устаревшая визуальная библиотека.

Реальные потребители v2: четыре заставки Cassandra и `p01-a02-history-index`,
`p01-a03-history-consistency`, `p01-a04-history-launch`. Они являются рабочими
примерами; предметные данные и монтажные границы в них не универсальны.
Совместимые episode-local re-export пути помечены `@deprecated`.

При рефакторинге сравнить кадры до/после: вход, читаемое состояние, переходы,
hold и выход; проверить 640×360 и альфу. Не менять принятый вид ради архитектуры.
MOV создавать только по запросу, через `task render:capcut`; для экспорта
`previewBackground: "transparent", withAudio: false`.
